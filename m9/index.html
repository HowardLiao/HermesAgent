M9 端到端技術架構與 220+ API 總體拓撲

L4 深度逆向
1.1 雙軌端到端系統拓撲

M9 系統採用前後端完全分離之單一免轉錢包（Seamless Wallet API）架構：

前端玩家大廳 (Template M21)
  • Vue 3 SPA 響應式排版，深色電競風視覺。
  • 無縫聚合 20+ 原廠場館（PG, EVO, JILI, SA, SBOBET 等）。
  • TCP/WebSocket 全雙工長連線（餘額推播、跑馬燈大獎、踢線廣播）。
  • 在地化 PromptPay QR Code 掃碼存款與提款打碼量即時校驗。
  • 斗雞專區直播模組動態開關（Vuex: showDouji）。
超級總控後台 (SuperAdmin)
  • D2Admin + Vue + Element UI，370 個前端組件 Chunks。
  • 基於 Casbin 的 RESTful API 細粒度權限控制（p, sub, obj, act）。
  • 四維關聯反查圖譜（IP / APP 機碼 / 銀行卡 / 免洗信箱）。
  • Doudou 自動化清算機器人（簡訊/推播監聽與 Android 自動代付）。
  • 多租戶多站點獨立網域、授信額度調撥與全量操作審計日誌。

商業模式 建置與入門門檻 每月固定支出 抽成與營運特點
買斷全套源碼 (Self-Hosted) $35,000 ~ $60,000 USD (約 110萬 ~ 190萬 TWD) + 原廠押金 $20k~$50k 技術維運團隊薪資約 40萬 ~ 65萬 TWD / 月 掌握底層代碼，自建 Doudou 機器人與金流網關，長期利潤率提升 12%~15%，但需承擔資安攻擊與運維風險。
SaaS 白標開線 (White-Label) $3,000 ~ $8,000 USD (約 10萬 ~ 25萬 TWD) 一次性開站費 系統維護費 $1,500 ~ $3,000 USD / 月 場館抽成 8% ~ 14% GGR (通常有每月保底消耗)，開站快 (3~5 天)，適合輕資產驗證渠道流量。
★ 真實利潤漏斗（毛利背後的剛性扣除項）：
毛利 GGR － 原廠場館費 (8%~14%) － 在地代收代付通道成本 (2%~3.5%) － 高防 CDN/抗 DDoS 盾與防封域名池 (每月數千美元) － 網銀凍卡死帳壞帳準備 － 代理佣金與贈金補貼 ＝ 真實沉澱淨利潤極為薄弱。

營運報表全景盤點與 12 大日週月缺漏模型

BI & 決策精準度
3.1 企業級必備之 12 張關鍵缺漏報表
時效維度 缺漏之關鍵報表名稱 精算公式與管理目的
日報1. 每日未結算負債與準備金平帳表充足率 = (實體卡資產 + 三方餘額) / (玩家錢包總額 + 浮動未結算注單) × 100%。若 < 100% 立即告警熔斷，防內鬼偷調帳或黑客雙花。
日報2. 日金流漏斗與掉單損耗分析表監控：點擊充值 → 生成 QR → 實際轉帳 → 機器人自動上分。秒級定位泰國網銀維護或電信阻斷。
日報3. 日對沖套利與異常打水巡檢表自動掃描百家樂同桌莊閒對沖 (佔比 > 90%)、輪盤全包、Slot 幽靈積累。每日晨會產出 Top 50 處置清單。
日報4. 高淨值大戶日流失與沉默預警表VIP 3+ 單日虧損 > 10 萬 THB 且餘額歸零、或 48 小時未登入者，自動派工單發放救援彩金挽回大戶。
週報5. 週遊戲實際 RTP 與數學偏差檢驗表滾動比對各老虎機「理論 RTP」與「實際 RTP = 派彩/投注」。若連續一週實際 RTP > 108%，立即排查漏洞或下架。
週報6. 週新客同梯次留存追蹤表追蹤首存 (FTD) 之 D1/D3/D7 留存率。若某代理名下 D3 留存為 0%，證實為羊毛假量，扣發佣金。
週報7. 週 VIP 升降級動態矩陣表統計晉級、保級、降級人次與淨貢獻，評估金字塔結構是良性流動還是基底萎縮。
週報8. 週客訴爭議與卡單熱點分析表分析充值未到帳、提款卡單、原廠斷線抱怨熱點，量化平均結案時長，作為與原廠談判扣款籌碼。
月報9. 月度真實淨利潤瀑布表公式：GGR毛利 - 原廠場館費 - 金流費 - 活動贈金 - 防封剛性支出 - 凍卡死帳 - 代理佣金 = 真實月度淨利潤。
月報10. 月度 CAC vs LTV 回本模型計算各渠道獲客成本 (CAC) 與用戶 1~3 個月累計貢獻淨額 (LTV)，精確得出渠道回本天數。
月報11. 月度場館效益與保底產出比統計各廠商「實際消耗抽成 / 最低保底費比率」，果斷終止連續三個月白繳空轉費用的冷門場館。
月報12. 月度卡池健康與沉澱死帳審計表統計月度採購卡片數量、存活天數、泰國警方凍結死帳資金總額，精確提列「壞帳準備金」。

M9 核心優勢 vs 我司（盛欣網絡《鬥陣江湖》）架構需求轉化

去博弈化・合規落地
5.1 嚴格合規底線與六大核心需求架構

盛欣網絡核心業務為俱樂部代理商房卡批銷模式（二元制衡），產品嚴格僅有「房卡/開桌服務費」， 嚴禁任何虛寶、道具、藥水、時裝、轉蛋抽卡或賭資兌現。風格嚴格定位為「台味國風江湖武俠風」（客棧紅木桌、熊貓大俠潘達、暗棋麻將）。

M9 技術優勢 我司（盛欣網絡）需求轉化與落實規範 對接我司商業模式之實質效益
級差拆帳算法 俱樂部房卡批銷階梯清算引擎：依公會會長進貨量自動結算批銷折扣與房卡消耗返點。 徹底取代負盈利分成，形成合法的批發商折扣模型，激勵大會長建立合規推廣梯隊。
四維關聯圖譜 公平競技防夥牌反作弊系統：強化「GPS 距離 (<50m) + 同 WiFi IP + 同機碼」同桌排查。 保障《鬥陣江湖》暗棋、麻將之絕對公平性，徹底杜絕熟人通牌作弊，守護綠色商譽。
單一免轉中台 高併發房卡扣減與防雙花中台：落實「開桌預扣凍結、局畢實扣、流局秒級退還」機制。 數萬包廂高峰同時開桌時，房卡扣減 100% 強一致性、零掉卡、零雙花。
Casbin RBAC 治理 推廣與營運二元制衡內控系統：業務僅管推廣資質，營運專責額度派發，調帳雙人覆核。 落實上市櫃內控標準，杜絕單一部門專權超發房卡，所有變更留存前後 JSON 審計。
多租戶動態模板 國風江湖客棧微前端動態裝修：支援紅木茶桌、熊貓大俠潘達主題之 CDN 熱加載。 節慶活動與公會客棧牌匾微前端熱抽換，主客戶端免重新發版。
數據對帳閉環 房卡進銷存閉環與日平帳報表：檢驗「發行量 = 總控出庫 + 在庫 + 在手 + 開桌消耗」。 每日自動跑平帳檢驗，一旦出現未授權房卡增量秒級告警熔斷，維護虛擬房卡嚴肅性。

專案戰略決策：市場前景不樂觀與暫停推進說明函

高管決策信函
致兄弟 Leo、Ben 的決策說明信函（全文收錄）：

Leo、Ben：

這幾天我和內部技術智囊，把你們這套 M9 系統從前端排版到後台 220 多支 API 與架構邏輯，非常扎實、深入地研究了一整遍。 首先我必須發自內心地向兩位兄弟豎起大拇指！這套系統做得太漂亮、太硬核了！從單一免轉錢包、Doudou 極速自動清算，到四維關聯防作弊圖譜，透著你們團隊極深的實戰底子與血汗心血，我和團隊都極為佩服！

然而，回到商業經營的本質，除了產品本身夠不夠鋒利，身為掌舵者，更必須抬頭看戰場上的客觀氣候。我和內部經營層經過好幾輪非常嚴肅的推演與評估，必須誠懇且坦白地跟兩位說實話：我們對接下來整體海外市場的總體環境，考量是相當謹慎、甚至偏向不樂觀的。

主要有三個不得不正視的客觀現實：
1. 海外宏觀監管與金流風暴加劇：東南亞政策收緊劇烈，防封域名封鎖成倍上升，網銀人頭卡排查上升至跨國執法維度，資金沉澱壞帳風險極大。
2. 流量紅利見頂，剛性成本高漲：買量成本攀升，高防 CDN、抗 D 盾、跳轉池與場館抽成層層扣減，真實淨利潤被壓縮得極為微薄。
3. 我司上市櫃體制下的防禦性戰略約束：身為上市櫃集團資訊長與盛欣副總，背負著嚴厲的反洗錢（AML）實質稽核。集團明令「防禦優先、固本培元、保守控管現金流」，全力聚焦於我們現有的《鬥陣江湖》綠色房卡棋牌生態。

基於上述客觀難點，經過內部慎重討論，我們決定：在現階段暫停這個專案的合作推進。
我想跟兩位兄弟說的是：這個暫停，絕非你們的產品不好——相反地，你們的技術無可挑剔。這個決定，純粹是我們在面對大環境風暴時，不得不做出的戰略踩煞車。

商業這條路很長，有時懂得留存實力是更成熟的智慧。生意有起伏，但兄弟的情分與我對你們才華的敬重永遠不變！未來如果海外氣候回暖，或是兩位考慮將高併發網關、圖風控引擎獨立出來做合規 B2B 科技服務，我 Howard 隨時在台北歡迎兩位！

Howard Liao Ph.D. (廖倫豪 博士) 敬筆
